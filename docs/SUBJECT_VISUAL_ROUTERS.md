# Subject-Aware Visual Routers

The platform routes concepts to 4 domain visualizers:

### 1. Math & Physics
- Renders LaTeX governing equations.
- Generates dynamic coordinate plots and trajectory charts.
- Provides step-by-step first-principles analytical derivations.

### 2. Biology & Life Sciences
- Renders high-resolution interactive SVG anatomical/cellular diagrams.
- Interactive structural component cards detailing specific biological roles.

### 3. History & Chronology
- Renders chronological event milestones and timelines.
- Categorizes eras, historical triggers, and geopolitical contexts.

### 4. Computer Science & Code Execution
- Real Python code runner with isolated execution sandbox.
- Captures standard output and runtime execution errors.
